### 🧠 Deep Learning Spiral Classification

Neural-network experiment studying the effects of regularisation on a noisy three-class spiral dataset.

Compared baseline and regularised neural networks using:

- L2 regularisation
- Dropout
- Early stopping
- Learning-rate experimentation
- Decision-boundary analysis

Reported test accuracy improved from **91.7% to 96.67%** after regularisation.

**Technologies:**  
`TensorFlow` · `Keras` · `scikit-learn` · `NumPy` · `Matplotlib`

🔗 [Spiral Classification Repository](https://github.com/abbasi303/spiral-classification-regularization)
